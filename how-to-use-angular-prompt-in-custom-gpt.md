
# 🚀 How to Use Angular 19 Prompt in a Custom GPT (ChatGPT)

## ✅ Step 1: Go to ChatGPT > Explore GPTs
1. Visit: [https://chat.openai.com/gpts](https://chat.openai.com/gpts)
2. Click **"Create a GPT"** in the top-right corner.

---

## ✅ Step 2: Start the Custom GPT Builder
1. Click “**Create**” to launch the GPT builder.
2. Fill in:
   - **Name**: `Angular 19 Expert AI`
   - **Description**: A frontend specialist trained on Angular 19, RxJS, Tailwind CSS, and Signals. Helps build clean, scalable, production-ready apps.

---

## ✅ Step 3: Paste the Angular Prompt
1. When asked for **system instructions**, paste your Angular prompt.
2. You can copy it from your downloaded file: `angular-expert-ai-prompt.md`
3. This instructs the AI how to behave like a true Angular 19 expert.

---

## ✅ Step 4: Add Optional Customization
- Add **example questions** like:
  - “Generate a standalone login component with Angular signals and Tailwind.”
  - “Show me a reactive form using FormGroup and custom validation.”
- Upload a logo (optional).
- Set **category** as: `Software Development` or `Frontend`.

---

## ✅ Step 5: Save and Start Using
1. Click **Save**.
2. You can now chat with your AI like this:

```
Create a signal-based user profile component with Angular 19 and Tailwind CSS.
```

---

## 💡 Bonus Tip: Share It!
After saving, you’ll get a **unique GPT link** like:
```
https://chat.openai.com/gpts/your-angular-expert-id
```

You can include this in LinkedIn posts, resumes, or share with your dev team!

---

**Enjoy building faster with AI + Angular! 🚀**
